# Screenshots

Drop the images referenced by the main README here, using exactly these
filenames — the README already points at them, so a file appearing is all it
takes for the image to show up.

| File | What it should show | Suggested size |
|---|---|---|
| `table.png` | A table in its ordinary state: toolbar, a few rows, the footer. The hero image, so make it the most representative one. | 1600×900 |
| `filters.png` | The filter builder open, with a nested AND/OR group. | 1400×900 |
| `columns.png` | The "Edit columns" panel, ideally mid-way through adding a relationship column. | 1000×900 |
| `header-menu.png` | A column header menu open, showing sort, group, filter, width, move, hide. | 900×600 |
| `views.png` | The saved-views picker, with an owned view and a shared one. | 1000×700 |
| `editing.png` | A cell being edited inline, or the bulk-edit panel over a selection. | 1400×800 |
| `responsive.png` | The same table on a narrow screen, with a child row expanded. | 800×1000 |
| `dark.png` | Any of the above in dark mode, to show the scheme switch. | 1600×900 |
| `themes.png` | The same table in two themes side by side. | 1600×700 |

Notes for whoever takes them:

- Use the demo application (`demo/`), seeded — the data there is realistic and
  already translated, so an Arabic or Hebrew shot is one language switch away.
- Keep the browser chrome out of the frame.
- PNG, and run them through an optimiser; GitHub serves the README to everyone
  who lands on the repository.
